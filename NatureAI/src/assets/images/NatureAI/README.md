# NatureAI - Where Nature Meets Technology

NatureAI is a modern React application showcasing a fictional AI company that draws inspiration from natural patterns and systems to create more efficient, adaptive, and sustainable AI solutions.

## 🌿 Project Overview

This project demonstrates a complete React website with:

- Responsive design that works on all devices
- Nature-inspired UI with organic shapes and flowing animations
- Modern React patterns using hooks and functional components
- Framer Motion for smooth, natural animations
- React Router for seamless navigation
- Tailwind CSS for styling with custom nature-inspired design system

## 🚀 Getting Started

### Prerequisites

- Node.js (v14.0.0 or higher)
- npm or yarn

### Installation

1. Clone the repository
2. Install dependencies:

```bash
cd NatureAI
npm install
# or
yarn install
```

3. Start the development server:

```bash
npm run dev
# or
yarn dev
```

4. Open your browser and visit `http://localhost:3000`

## 📱 Features

- **Home Page**: Showcases the main product offering with a hero section and feature highlights

## 🎨 Design Elements

The UI design combines organic, flowing shapes with tech-inspired elements:

- **Color Palette**: Soft greens, earthy browns, sky blues with metallic accents
- **Shapes**: Mix of rounded organic shapes and geometric tech patterns
- **Typography**: Clean, modern sans-serif fonts for readability
- **Animations**: Subtle, smooth movements that mimic natural flows
