# Nature-Inspired AI Project

A minimalist React application with a focus on organic shapes and natural colors. This project features a clean, nature-inspired UI with smooth animations and fluid interactions.

## Features

- Minimalist UI with organic shapes and natural colors
- Smooth, fluid animations for a natural feel
- Responsive design that works on all devices
- Nature-inspired components and illustrations
- Four main pages: Home, About, AI Features, and Contact

## Tech Stack

- React 18
- Vite
- Tailwind CSS for styling
- Framer Motion for animations
- React Router for navigation

## Getting Started

### Prerequisites

- Node.js 14.0 or later
- npm or yarn

### Installation

1. Clone the repository
```bash
git clone <repository-url>
cd ai-project
```

2. Install dependencies
```bash
npm install
# or
yarn
```

3. Start the development server
```bash
npm run dev
# or
yarn dev
```

4. Open your browser and navigate to `http://localhost:5173`

## Build for Production

```bash
npm run build
# or
yarn build
```

The built files will be in the `dist` directory.

## Preview Production Build

```bash
npm run preview
# or
yarn preview
```

## Project Structure

- `src/components/` - React components
- `src/assets/` - Static assets like images
- `src/App.jsx` - Main application component
- `src/main.jsx` - Application entry point

## Design Elements

- **Color Palette**: Soft whites, sage green, sky blue, earth tones
- **Typography**: Quicksand (rounded sans-serif font)
- **UI Elements**: Soft, rounded corners and organic shapes
- **Animations**: Smooth, fluid transitions and interactions
