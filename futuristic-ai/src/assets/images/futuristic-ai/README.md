# Futuristic AI Interface

A modern React application with a futuristic UI design that showcases AI technology capabilities. This project features a sleek, dark-themed interface with neon accents and cutting-edge visual effects.

## Features

- Futuristic UI with dark color scheme and neon accents
- Responsive design for all device sizes
- Interactive animated components
- Particle background effects
- Holographic displays and data visualizations
- Multi-page layout with smooth transitions

## Pages

- **Home** - Main landing page with AI technology overview
- **Features** - Detailed breakdown of AI capabilities
- **Dashboard** - Interactive AI system monitoring interface
- **About** - Company background and team information
- **Contact** - Contact form and company information

## Technologies Used

- React
- Vite
- React Router
- Framer Motion (for animations)
- React Icons
- Custom CSS with variables

## Getting Started

### Prerequisites

- Node.js (v14 or newer)
- npm or yarn

### Installation

1. Clone the repository
   ```
   git clone https://github.com/yourusername/futuristic-ai.git
   cd futuristic-ai
   ```

2. Install dependencies
   ```
   npm install
   # or
   yarn
   ```

3. Start the development server
   ```
   npm run dev
   # or
   yarn dev
   ```

4. Open your browser and navigate to `http://localhost:5173`
