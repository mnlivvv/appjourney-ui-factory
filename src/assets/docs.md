# Retro Arcade Todo App - How to Use

## Features

- **Add Todos**: Create new missions with optional due dates
- **Complete Todos**: Click on a todo to mark it as completed
- **Delete Todos**: Remove unwanted todos
- **High Score**: Track your progress with a high score board
- **Sound Effects**: Enjoy retro arcade sound effects (can be toggled)
- **Filtering**: Filter todos by All, Active, or Completed
- **Game Over**: Past-due todos are marked as "GAME OVER"

## Game Mechanics

- Each todo is a "mission" with a randomly assigned level and point value
- Completing todos earns you points
- Reach higher player levels by earning more points
- Overdue todos count as "Game Overs" on your score board

## Sound Effects

- Add Todo: Notification sound
- Complete Todo: Success sound
- Delete Todo: Buzzer sound
- Level Up: Level up jingle
- Game Over: Game over sound
- Click: Button click sound

## Keyboard Shortcuts

- Enter: Submit new todo
- Escape: Close expanded form
- Space: Toggle sound on/off when focused on sound button
