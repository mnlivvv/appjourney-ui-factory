# Todo Notebook App

A beautiful todos app that mimics the look and feel of a physical notebook or planner. 

## Features

- Realistic notebook design with paper texture and spiral binding
- Tasks appear as handwritten text
- Completed tasks get dog-eared corners
- Sticky notes and paperclip visual elements
- Local storage persistence

## Getting Started

1. Clone this repository
2. Install dependencies:
   ```
   npm install
   ```
3. Run the development server:
   ```
   npm run dev
   ```

## Build for Production

```
npm run build
```

## Technologies Used

- React
- Vite
- UUID for unique IDs
- CSS for styling and animations
